GIT
Check the connection
git remote -v — shows which repo (which URL) you're connected to.

Check your state — your most important command
git status — what's changed, what's not yet committed, what's untracked, and whether you're in sync with the server. Look at it before and after every step.

See what's committed
git log --oneline — list of all your commits, one per line.
git show --stat — which files are in the last commit.
git ls-tree -r --name-only HEAD — all files in the newest commit, with folder structure.

The workflow
git add . — stage all changes (or target one: git add file.c).
git commit -m "message" — capture the snapshot.
git push — upload to the server.

The real server check
git clone <url> check-copy (in /tmp) then ls -R — pull a fresh copy from the server and look at what's actually up there. The most reliable check before evaluation.


git log - show last commits
git log -3 show the last 3 commits
git log --pretty=format:"%H" show only IDs (H for long IDs, h for short IDs)

Specifications for git log --pretty=format:"..."
